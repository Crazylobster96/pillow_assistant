## 边界复核

- 空文件：发布零 chunk 的 `empty` document，不作为错误命中。
- 超大文件：超过限制时 `too_large`，允许用户调整后重试。
- 编码失败：`unreadable`，保存路径和错误类型，不保存异常正文。
- 相同路径替换：fingerprint 变化产生新 generation。
- 路径大小写/符号链接：使用平台规范化路径作为 identity，同时保留 original path 展示。
- 删除后重建：tombstone 优先于队列中的旧 ingest 任务。
- 远程 provider 返回重复项：以 provider result id + profile 去重。
- 查询超时：返回明确 degraded/timeout，不伪装成无结果。

需求已覆盖能力替换、数据边界、SaaS 同意、索引一致性、混合召回、故障降级、费用、删除和兼容性，可进入函数级设计。
