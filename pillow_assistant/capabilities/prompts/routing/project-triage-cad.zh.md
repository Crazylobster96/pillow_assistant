本次是 CAD / 建模 / CAM / 概念图类请求，请独立判断项目归属：
- 按设计对象判断（同一个零件、产品、装配体或同一套图），不要因为某个项目当前开着就归入它；与所有已有项目的设计对象都不同就 new。
- 需要产出模型、图纸、刀路或图片文件的 CAD 请求不要判为 chat；只问概念、软件用法这类不产出文件的才是 chat。
- new 时用设计对象给项目命名（如「齿轮箱外壳」「无人机机架」），不要用「CAD项目」「建模任务」这类泛称。
- 对同一设计对象做 CAM 加工、Anatomy 演示图（概念图/爆炸图）属于延续：continue 该 CAD 项目，可直接用它的模型与脚本。
- 若是基于某个已有项目的成果另做一个新设计（新版本、变体、用到它的零件的新产品），action=new，并在 JSON 里加 "inherit_from":<那个项目的 id>，系统会把它的成果复制进新项目继续开发。
